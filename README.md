# Zenvia — Fashion Intelligence Platform

A full-stack fashion platform with seasonal colour analysis (ResNet-50 ensemble),
real-time body-size estimation (MediaPipe), a virtual wardrobe, product discovery
via Google Shopping, and an AI fashion chatbot powered by Mistral.
